# 智训引擎：由大模型驱动的受控工业模型续训 Harness

版本日期：2026-11-17。接口为官方 `contest_harness` 1.0.2，
协议 `contest.harness.workspace.v2`，模型访问 `host_gateway_rpc`。
SDK由赛题官网公开下载，原包SHA256为
`c676c8beeef69cece9cbec5a633d05dbb9832eb22b6f761913f2315bd1f85133`，源文件保持不变。

## 任务与交付

支持六类气体识别、轴承剩余寿命和发动机剩余寿命，即分类与回归两类任务。
平台按数据集分配十个回合，镜像每次执行一个平台回合，不自行重复读取本地数据模拟十个阶段。
固定入口为 `/app/harness.py describe|train|predict`。

镜像包含程序、官方SDK、依赖和来源声明，不包含本地训练/验证集、历史已训练权重、
PyTRIO密钥或外部采样客户端。训练只读取SDK授权公开投影，续训只从父产物清单声明、
经SDK校验摘要的CPU检查点开始。隐藏集不挂入训练进程。

## 方法

每回合先读取平台历史、父模型和本轮公开数据，用父模型的冻结特征路径解析输入。
训练集和验证集ID交集被拒绝。沿用父模型均值、尺度、目标缩放和Adam状态，不重新初始化模型。

Harness向 `rnd.model()` 请求训练计划。模型身份由平台绑定提交表单中的Sampler或基础模型，
官方任务提示由宿主注入，选手程序不重复添加。模型读取历史、当前公开指标及真实训练工具代码，
通过受限的 `write_training_plan` 工具修改Python字面量训练计划；宿主渲染并重新解析该计划后执行。
这属于有限工具Agent，不声称可以任意编辑和执行任意Python程序。

计划限定为hold或retrain、最多十个epoch、学习率不高于0.001。
分类可使用由当前授权训练标签计算的类权重，回归保留原有损失与目标单位。
代码拒绝导入、函数调用表达式、未知字段和非有限值，保留超时及格式错误记录。
计划无效时最多进行一次模型修复请求，再失败则保守保留父模型。

候选仅用训练集更新。验证集用于公开诊断和选择，不参与梯度更新或归一化拟合。
提交候选后，平台测量回执原样反馈给模型，由第二次模型请求选择候选或父模型。
本地质量门槛还要求分类Macro-F1增加且准确率不下降，回归RMSE下降且MAE不增加。
本地计算与平台回执分开记录，不将本地指标冒充平台分数。

训练、计划文件、模型回执号、历史引用、真实候选变化及选择理由写入原生状态。
正常回合执行两次模型请求，计划修复时增加一次。网关请求失败不会伪造调用号继续提交。
同一数据集下一回合读取平台选定的父产物与只读状态副本，所有写入位于 `/workspace`。

## 预测与资源边界

预测通过SDK接收每行无标签输入，使用 `/model` 中选中检查点。
每读一行立即预测、输出并刷新，不等待EOF，不请求大模型，不依赖完整隐藏批次。
分类输出冻结类别的有限概率，处理并列最高分；回归输出非负原单位数值。
该版本不启用需要完整目标批次的CORAL研究接口。

程序使用NumPy CPU计算和单线程BLAS，容器以UID/GID 65534运行。
根文件系统、程序、数据、父模型和预测产物可保持只读；只有工作区和临时目录可写。
保留每轮训练时限及候选采用门槛。大模型输出token上限服从平台帧授权。

## 验证结果与实际限制

本轮项目116项单元测试和官方SDK15项原始离线测试通过。
容器完成A连续三轮、B/C各一轮的真实公开数据续训检查；验证历史引用、状态复制、
候选提交、选择与确认，并验证预测在stdin尚未结束时逐行返回。
原始输入、vendor参考实现及历史检查点的217个受保护文件保持不变。

这些检查的模型回包由本地宿主替身提供，明确不是平台或真实Sampler推理结果。
当前没有正式隐藏评测成绩，也未在本地宣称完整平台三十轮已完成。
真实Sampler可访问性、模型输出质量及隐藏任务效果应以平台试运行和正式评测为准。
